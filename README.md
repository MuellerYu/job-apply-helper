# 求职自动投递助手（分享版）

一个 Chrome 插件：在招聘网站的申请页上，自动上传简历、按你的资料填表、逐页往下点，**停在提交前**让你自己检查再提交。

- 支持 Workday、Greenhouse、Lever、Oracle、iCIMS、SuccessFactors、Paylocity、Jobvite 等主流招聘系统，其他网站用通用方式填写。
- 配合你电脑上的 **Codex**（ChatGPT 桌面版自带）还能做这些：
  - 回答插件规则答不了的新题，作文题也能写；
  - 每页填完复核一遍；
  - 操作插件不认识的下拉框；
  - 写一页的 cover letter 并自动上传。
- 适用于 **Mac + Google Chrome**。

---

## 一、安装（大约 5 分钟）

1. **下载**（二选一）
   - 会用 git：在终端运行 `git clone https://github.com/MuellerYu/job-apply-helper.git ~/Documents/job-apply-helper`。
   - 不会用 git：打开 https://github.com/MuellerYu/job-apply-helper ，点绿色的「Code」→「Download ZIP」，解压。
   - 把文件夹放到一个固定位置，比如「文稿」，之后不要再挪动或改名。
2. **装进 Chrome**
   - 地址栏打开 `chrome://extensions`，打开右上角「开发者模式」。
   - 点「加载已解压的扩展程序」，选这个文件夹。
   - 装好后会自动打开设置页。以后点工具栏上的插件图标也能打开。
3. **装 Codex 连接**（要用 AI 功能才需要这一步）
   1. 安装 ChatGPT 桌面版（https://chatgpt.com/download）并登录，打开一次里面的 Codex。也可以用命令行：先 `brew install codex`，再 `codex login`。
   2. 打开「终端」，输入 `bash `（bash 后面有个空格），把文件夹里的 `native-host/install.sh` 拖进终端窗口，回车。
   3. 回到插件设置页，点「AI（本机 Codex）」里的「测试连接」，显示「已连上」就好了。

## 二、填资料（第一次用时做一遍）

在设置页里按顺序做：

1. **上传简历**
   - 在「简历」一栏点「添加一份简历」，选 PDF。
   - 可以传好几份（比如 Finance / Audit 各一份），每份写上关键词，插件会按职位自动挑一份。
   - 选一份设为「默认」。
2. **点「用简历自动填写资料（Codex）」**
   - 它会读你的简历，自动填好姓名、联系方式、学校、学位、专业、GPA、技能、工作经历和项目。
   - 只填还空着的项，已经填过的不会被覆盖。
3. **从上往下检查一遍，补上简历里没有的**
   - **基本信息**：地址、邮编、电话（只填号码，不带 +1）。
   - **常见申请问题**：签证身份、是否需要担保、能否搬家，还有各种「是否…」的题。
     - 选 Yes 或 No，插件遇到这类题就会自动答。
     - 留「（不自动回答）」的题，插件会标红停下，交给你或 Codex。
   - **背景和经历**：「背景补充」框可以随便写，Codex 答题、写 cover letter 时都会参考。比如：
     - 签证身份、住在哪；
     - 只想在教育栏写哪个学位；
     - 某类题想怎么答；
     - 哪些事不要写。
   - **自愿披露**（性别、种族、退伍军人、残障）：按实际选，不想说就选「不愿透露」。
4. 点最下面的 **「保存」**。

资料要用**英文**填，因为申请表都是英文的。

## 三、投递

1. 打开一个职位的申请页（Workday 页面直接打开职位就行），右下角会出现「自动投递」面板。
2. 点 **「自动到提交前」**（Workday 上叫「自动到 Review」），插件会：
   - 上传简历；
   - 按资料填好每一页，遇到新题交给 Codex 回答；
   - 有 cover letter 栏就让 Codex 写一封传上去；
   - 自动点「下一步」，一直走到最后一页。
3. 停下来的时候看面板上的提示：
   - **「还有 N 个必填项没填（已标红）」**：手动答完，再点一次「自动到…」。你手动答过的题，插件会记住，下次自动答。
   - **「已到 Review 页 / 已经填到最后一页」**：从头检查一遍，**自己点 Submit**。
4. 验证码、人机验证（reCAPTCHA / hCaptcha）、邮箱验证码、注册账号设密码，都要你自己来，插件不碰。

### 批量投递（一次投很多个）

1. 设置页最上面点 **「📋 批量投递队列」**。
2. 「导入职位」里选一个 CSV 文件。要有「链接」列，可选列：company、title、location、建议简历版本（写简历的名字，比如 Finance）、优先分。同一家公司默认最多投 3 个。
3. 点 **「开始」**。插件同时打开几个职位（默认 5 个，「同时投几个」可以改），自己点 Apply、填表。
   - 「填完自动提交」**不勾**：每份停在最后一页，标签页留着等你检查、自己点 Submit。
   - **勾上**：插件自己交。不建议一开始就勾，先看几份它填得对不对。
4. 要登录 / 注册、邮箱验证码、人机验证的，标签页会留着，列在「等你处理」里。同一个网站只要你登录一次，之后这家的职位会接着投。注册时用 Chrome 建议的强密码，以后 Chrome 会自动填。
5. 留着等你的标签页满 12 个时队列会暂停，处理掉几个再点「开始」。

资料里的「常用名 Preferred Name」：有英文名就填上，表格里问 Preferred Name / Nickname 时会用它；没有就空着，这类题会留空。

## 四、更新

- 有新版本时，设置页最上面会出现黄色提示。
- 更新方法：双击插件文件夹里的 **「更新.command」**。如果 macOS 不让打开，就在终端里输入 `bash `（bash 后面有个空格），把它拖进来，回车。
  - 用 git 下载的会自动 `git pull`；用 ZIP 下载的会自动下载最新版覆盖。
  - 本地连接（Codex）也会一起更新。
- 更新完刷新任意网页，插件会自动换成新版本。
- 你的资料、简历、投递记录都存在 Chrome 里，更新不会丢。

## 五、常见问题

- **面板没出来**：先刷新页面。还不出来的话，到 `chrome://extensions` 里点插件的刷新按钮，再刷新页面。
- **测试连接失败**：在终端重新运行一次 `install.sh`，看它有没有提示找不到 Codex。
- **cover letter 在哪**：桌面上「求职材料/Cover Letters」文件夹里，按顺序编号。第一次写的时候，macOS 可能会问「Google Chrome 想要控制访达」，点「好」。
- **想关掉某个功能**：设置页的「行为设置」里可以关：Codex 补答、整页复核、AI 操作员、cover letter、自动勾选同意条款等。
- **投递记录、答卷记录**：都在设置页下面，可以导出 CSV。
- **换电脑或备份**：设置页最下面「备份」，可以导出或导入全部设置。

## 六、隐私

- 你的资料、简历只存在你自己的 Chrome 里（`chrome.storage`）。
- 只有用到 AI 功能时，才会通过本机的 Codex 发给 OpenAI，并且用的是你自己的 ChatGPT 账号。
- 插件不会替你点最终的「提交」按钮。如果在设置里打开了「到 Review 页后自动点 Submit」，它才会自动提交，这项默认是关着的，不建议打开。
